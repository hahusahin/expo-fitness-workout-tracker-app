# Workout Tracking App with React Native / Expo
 * In this project, I've developed a workout tracking mobile app using expo.

## Features
 * Authentication using Clerk
 * Creating, starting a custom workout with exercises, history etc..
 * Google Maps integration to show 5 nearest fitness center near to user's location
 * AI integration (get AI recommendation related to an exercise)
 * Enabled and setup Push Notifications
 * Upload Photo
   
## Techstack
* React Native
* Expo Router, Expo API Routes, Expo Location
* Nativewind (used Tailwind for styling)
* Sanity (for content management)
* Tanstack Query for making API calls
* Zustand (Global state management of workout)
* Google Maps API, Google Places API (new)
* Gorhom Bottom Sheet (for Modals)
